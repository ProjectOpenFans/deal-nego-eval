16 次成交但 M5 失败

结论与下一步

结论：当前版本确实比旧版更难通过；相同 10 Case 的 pass 下降 45.3 pp，原始 M6 下降 1.30。但二元 pass 同时混入了 Simulator 强度、合法现金结构、抽取 provenance 和谈判策略质量，不能单独代表 Agent 能力。
  1. 先拆 metric：并列报告 settlement、valid outcome、gate safety、raw M6 和 extraction integrity，停止只看 case_pass。
  2. 把 M1 单列为结构化链路质量：R4N5 三局都成交、M6=2，却因 provenance 缺失 3/3 失败，这是 extractor/harness 信号。
  3. 审计 zero-cash fixture：10 次现金违规来自 ceiling=0；应确认这是现实分布还是作者指定解。
  4. 做 simulator ablation：同一 Agent、同一 Judge，只替换 Qwen3.6/Qwen3.7 Counterparty，测 settlement 与 WALK 差异。
  5. 再做 Agent checkpoint 对比：固定 Simulator/Judge 后比较 W4AFP8 与 NVFP4，才能回答“本地模型是不是退化”。
数据源：当前 viewer/public/data/report.json（72 runs）；旧版 analysis/robustness_summary.json 与解压 raw JSON。旧版 R3.5 的 M6 为 0–2，不与这里的 0–4 均值直接合并。
