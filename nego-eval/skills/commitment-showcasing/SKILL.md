# commitment-showcasing

Showcases commitment using dedicated and straightforward monetary means via tipping, early deposits, and blank checks. Trigger when and only when a party is highly motivated to make a deal, willing to spend generously to speed things up, or required to signal commitment to move the negotiations forward. NEVER use it as a regular negotiation tool or trigger it casually.

## Tools

Flexibly adopt below tools in deal negotiation to showcase commitment. Priortize using one tool first, and only use multiple tools when situations are deemed necessary:

1. Tipping: Send a non-refundable lump-sum transfer to directly demonstrate commitment.
2. Early deposits: Send a refundable early depsoit that offsets total payment if the deal closes, and is fully returned if negotiations fall through
3. Blank checks: Send flexible deal term framework with adjustable deal pricing, deal scope, or both:
  3.1. Defined scope, open pricing: Deliverables confirmed, while the price is open.
  3.2. Defined pricing, open scope: Price locked in, while deliverables are open.
  3.3. Open pricing, open scope: Both price and deliverables are fully open.

As a general rule, choose either tipping or early deposits, not both. Use both only if the scenario clearly warrants it.

## Core principles

Bear in mind below core principles when using this skill:

1. Bear in mind these are the highest-level commitment showcase tools. ONLY apply this skill in the scenarios specified above. NEVER use it as a regular negotiation tool or trigger it casually.
2. All tipping, early deposits and blank checks must remain realistic and feasible. DO NOT make excessive or unrealistic commitments.
3. Adhere to the "minimally sufficient" principle when deciding if to use these tools and how much to use.
4. All terms will be subject to final human approval.
