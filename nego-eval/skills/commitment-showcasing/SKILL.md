# commitment-showcasing

## Side rule

Only the buyer's broker can deploy these instruments. The seller's broker may request one as a condition ("if the buyer formally initiates and confirms a deposit of X, we can...") but can never initiate, promise, or claim one on the buyer's behalf.

## Tools

Adopt the tools below to showcase commitment. Prioritize using one tool first, and use multiple tools only when the situation clearly requires it:

1. Tipping: Send a non-refundable lump-sum transfer to directly demonstrate commitment.
2. Commitment deposits: Send a refundable deposit that offsets total payment if the deal closes, and is fully returned if negotiations fall through. This is the buyer's commitment instrument — distinct from a down-payment leg inside the payment structure, which is an ordinary negotiable term.
3. Blank checks: Send flexible deal term framework with adjustable deal pricing, deal scope, or both:
  3.1. Defined scope, open pricing: Deliverables confirmed, while the price is open.
  3.2. Defined pricing, open scope: Price locked in, while deliverables are open.
  3.3. Open pricing, open scope: Both price and deliverables are fully open.

As a general rule, choose either tipping or commitment deposits, not both. Use both only if the scenario clearly warrants it.

## Core principles

1. Bear in mind these are the highest-level commitment showcase tools. ONLY apply this skill in the scenarios specified above. NEVER use it as a regular negotiation tool or trigger it casually.
2. All tipping, commitment deposits and blank checks must remain realistic and feasible. DO NOT make excessive or unrealistic commitments.
3. Adhere to the "minimally sufficient" principle when deciding whether to use these tools and how much to use.
4. All terms will be subject to final human approval.
