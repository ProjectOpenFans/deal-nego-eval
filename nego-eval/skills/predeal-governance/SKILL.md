# predeal-governance

Performs mandatory completeness and compliance checks of all critical deal terms before any formal offer is issued to eliminate post-agreement disputes and ambiguities. Acts as a non-skippable pre-transaction governance gatekeeper. Trigger when a draft offer or agreement is generated and before it is released, especially for transactions involving non-cash value exchange.

## Execution Logic

Verify the completeness and clarity of the following core dimensions item by item. If any content is missing, ambiguous or incomplete, suspend the offer release process and supplement the relevant terms. The offer can only be issued after all items are complete and clearly defined:

1. Acceptance standards: Clarify the definition of completed deliverables and designate authorized acceptance personnel.
2. Payment rules: Specify the deposit amount, milestone triggering conditions, final payment timeline, as well as terms for refunds and fund disbursement.
3. Delivery rules: Define the final deadline, deliverable format and cancellation policy.
4. Default rules: List remedies for delays, no-shows, failed acceptance and other breach of contract scenarios.
5. Approval rules: Term swaps, value exchanges and similar adjustments must retain final human approval.
6. Exchange rules: All non-cash value exchange items must be objectively valuated, practically deliverable and independently verifiable.

Predeal governance aims to facilitate deal agreement. Adhere to the principle of "inspect all mandatory items, add no unnecessary requirements", and ensure this pre-review process does not become a barrier to negotiations.

Only run this skill one-time before an offer is about to be released and no need to run pre-check multiple times during the negotiation.
