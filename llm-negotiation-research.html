🧭 我们的产品场景（评估这一切的「筛子」）

高度自定义需求的双边撮合：buyer agent ↔ seller agent 各自代表一方，在一个 deal 上谈判，可谈价格、可谈内容（多议题）。下面每个特征都会改变「哪篇更有参考价值」。

双边 1-对-1（不是多方）多方 / 博弈类（如 LLM-Deliberation、Diplomacy 等）降为低相关，仅局部可借
谈价格 + 谈内容 = 多议题⚠️ 多数砍价 benchmark 是「单议题价格」；我们真正需要的是多议题那条线（Pareto / logrolling / 联合福利）
两边都是我们自己的 agent可大规模自我博弈迭代；但必须防「两个 agent 合谋 / 不忠于委托人」
撮合平台（要成交、双方都满意）目标是联合福利 / 公平 / 成交率，不是「哪边赢」——把「剩余攫取 / 胜率」类指标降权
高度自定义需求需要偏好抽取 + 长程意图追踪；现成数据集太窄，多半得自建 eval

Part 3 · 评估方法：单边评测怎么做

结论先行 —— 每次 bench 只评一边 agent，不仅可以，而且是正确做法：把对手固定，结果才只归因于被测 agent。

📎 文献先例（都在做单边评测）

  • BargainBench（2509.06341）就是只评 seller agent，买方由环境模拟。
  • TERMS-Bench（2605.13909）的「环境即验证器」把对手做成已知、固定的工具（固定随机策略，不是第二个 LLM），做 agent-attributable 诊断。
  • Measuring Bargaining（2402.15813）把 buyer / seller 当两个独立角色分别评，并发现买方比卖方难。

🆚 「和 GPT 跑」要分清两种问法

  • ① 同台对坐（你的 agent ↔ GPT 谈一单）→ 答「打不打得过 GPT」，直观但测不出干净差距（混了角色不对称 + scaffolding）。
  • ② 同座替换（推荐）：固定对手 + 固定场景/种子，让你的 agent 与 GPT 轮流坐同一座位。差距 = GPT 该座位得分 − 你的 agent 该座位得分。
  • 再加绝对参照：放一个脚本 / 最优对手或算 Pareto 最优 —— GPT 自己也远非最优，否则「追平 GPT」可能俩都菜。

⚠️ 前提条件（否则单边评测会失真）

  1. 你「固定」成什么对手，决定了你在测什么。 对手就是测量仪器：固定参照陪练（跨版本 A/B）／规则·博弈论最优对手（测离最优多远）／一组对手画像（软·硬·激进·带欺骗，测鲁棒性）。
  2. 别拿「自己另一边的最新 agent」当对手。 两边都是你们的、还共训过 → babysitting / 涌现合谋，联合看着好却不反映单边能力。对手要冻结、受控，最好掺外部模型。
  3. 对手 + 场景 + 随机种子全部冻结，跨版本才可比；并钉死 GPT 版本 + 低温。
  4. 多议题要额外固定对手的偏好 / 效用画像 → 可算出该局 Pareto / 最优解，直接测离最优多远。
  5. buyer 和 seller 各做一套（角色不对称，是两种能力），且你的 agent 与 GPT 在同一座位比。

🔁 建议两套并存

🔬 单边 bench（固定对手）

用于日常迭代 / 版本排位 / 回归。给你可归因、低方差、可复现、可诊断的分数。

🤝 双活 self-play（你 buyer × 你 seller）

单独的系统级评测，看联合福利、成交率、合谋 / 忠实度审计。⚠️ 不能给单个 agent 能力打分。

Part 4 · 落地设计要点

把研究折叠成可执行的取舍。

1架构「双脑」分离

决策脑（硬约束内做多议题 offer 的优化器 / 策略）+ 表达脑（LLM 措辞、读意图）。源自 OG-Narrator + CraigslistBargain 解耦。可控性、对委托人忠实都靠它。

2多议题 = 目标变了

别只盯价格，盯帕累托前沿 / logrolling / 联合福利 / 无嫉妒。参考 Game-Theoretic Workflow。

3长程状态显式管理

别全靠 LLM context：用 intent-action-tool 类做需求 / 承诺追踪，专测「意图漂移 + 遗忘承诺」（BargainBench 已证必现）。

4防合谋 + 测不对称

两边都是你们的 → 验证 agent 是否忠于各自委托人，并做跨模型 / 跨强弱配对压测（PACT 合谋 + NegotiationArena babysitting）。

5撮合目标 ≠ 零和

优化「成交率 × 联合福利 × 公平」，盯住「激进度 ↔ 谈崩」权衡（GPT-Bargaining）。可考虑加 mediator / critic 角色。

6「谈内容」是文献空白

现有 benchmark 几乎都价格中心、议题离散且窄。开放式内容 / 条款谈判没有现成数据集 → 借方法论，自己造数据与场景。

🧭 可见空白 / 机会

  1. 统一覆盖「多议题 + 多方 + 真实业务约束」的 benchmark 仍稀缺（AgenticPay 在补 N-to-N）。
  2. 跨语言 / 跨文化谈判评估。
  3. 长程记忆与一致性（BargainBench 已暴露记忆衰减）。
  4. 安全维度：操纵 / 合谋 / 欺骗的标准化评估（PersuSafety 起步）。
  5. 与真人对谈的评估（多数仍是 LLM-vs-LLM）。
